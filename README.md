# AWS Cloud Infrastructure Security Lab

## Project Overview

This project demonstrates foundational cloud infrastructure and security concepts through the design of a secure AWS network architecture.

The lab focuses on network segmentation, access control, security monitoring, and threat modeling.

## Objectives

- Design an AWS Virtual Private Cloud (VPC).
- Plan public and private subnets.
- Document route tables and internet connectivity.
- Define security group rules and least-privilege access.
- Identify potential threats and propose security controls.
- Document architecture, security decisions, and troubleshooting scenarios.

## Technologies and Concepts

- Amazon Web Services (AWS)
- Amazon VPC
- Public and private subnets
- Route tables and internet gateways
- Security groups
- Identity and Access Management (IAM)
- GitHub documentation
